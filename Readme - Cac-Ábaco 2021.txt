Nome: Ábaco Cac-Ábaco (2021)
Local: https://scratch.mit.edu/projects/556597283/

   Programa adaptado para atender a várias bases numéricas (base 10, base 2, base 8 e base 16).
   Este programa visa ajudar alunos utilizarem as seguintes bases numéricas: binária, octal, decimal e hexa.

Instruções:
- basta selecionar uma das bases numéricas (2, 8, 10 ou 16);
- A base numérica escolhida é mostrada no mostrador à esquerda;
- Utilizar o Ábaco normalmente para contagem;
- Nos mostradores na parte inferior de cada casa numérica (1´casa, 2´casa e 3´casa), a quantidade de pinos acionadas são mostradas.

Limitações:
- Quando selecionar a base numérica 16 (hexa), a animação dos pinos irá até o nono (9´) pino. A versão atual não realiza a animação do décimo (10´) pino em diante. Porém, no mostrador inferior de cada casa numérica, a quantidade de pinos ativos são mostrados independente da animação não mostrar o décimo pino em diante.
